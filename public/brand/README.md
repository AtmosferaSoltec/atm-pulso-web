# Pulso visual identity

Vector monogram for the Atmósfera product family.

The proposed symbol combines a vertical stem, a separated bowl, and a circular pulse. It has a transparent background for the light interface and printed sheets. Original supplied SVG references remain unchanged.

- Petroleum blue: `#17677B` for primary actions and navigation.
- Teal: `#178E91` for highlights and charts.
- Light background: `#F5F7F9`; white cards and sidebar.
- Dark blue-gray: `#263745` for body text.

The logo uses a restrained blue-to-teal spectrum. Semantic green, amber, red, and blue identify valid, expiring, expired, and scheduled memberships.
